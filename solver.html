How to use

  • Click a slot to select where pasted image will go.
  • Use the Upload button to choose files normally.
  • Paste an image with Ctrl+V after selecting the slot.
  • The solver uses the fixed 43px grid size for the maze.
  • For Venn Diagram, open that tab, paste the diagram, and copy the generated notation.

Want more modules? Add new sections and menu buttons, then show them with showSection('sectionId').

This is a single-page maze solver. The UI is controlled entirely by JavaScript, so new menu modules can be added without reloading the page.

Keep the main logic in functions and add more sections if you want settings, debug panels, or other tools.
